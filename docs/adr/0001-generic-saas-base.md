# ADR-0001: Product: generic SaaS base

## Context

Any business will be built on this base, even different businesses per company. The model must not prevent that, but nothing is implemented for it now.

## Decision

- **Decision**: `companies`, `users` and `members` (memberships). No business logic.
- **Why**: any business will be built on this base, even different businesses per company. The model must not prevent that, but nothing is implemented for it now.

## Consequences

See Decision.
