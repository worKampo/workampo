2. **Cuenta de Gmail** del proyecto (✅ creada el 12 nov 2026; la dirección irá a `worKampo/business` cuando lo cree el ticket 2, nunca al repo público, [ADR-0043](../adr/0043-public-repo.md)): dueña de todas las cuentas siguientes y destino de avisos (GitHub, Cloudflare, Sentry, monitor). 3. **GitHub** (decidido el 12 nov 2026: **usuario + organización**; ✅ creados el 13 nov 2026): usuario **`workampo-dev`** con el Gmail del proyecto, 2FA y email privado (*noreply*), y organización **`worKampo`** (GitHub no distingue mayúsculas: `github.com/workampo`) en el plan Free, con 2FA obligatorio, dueña del repo público ([ADR-0043](../adr/0043-public-repo.md)). La organización encaja mejor con la GitHub App de los agentes ([ADR-0041](../adr/0041-agent-boundaries.md)), los rulesets y futuros colaboradores. El repo se crea en el ticket 1 de "Working foundation".
   - **Todo lo que sube a GitHub va con la cuenta del proyecto, con ninguna otra**. La máquina puede tener git, `gh` y Claude Code configurados globalmente para otros proyectos, así que la separación es por carpeta (✅ configurado y comprobado el 15 nov 2026):
     - **Identidad de git por carpeta**: un `includeIf "gitdir/i:<carpeta del proyecto>/"` en el `.gitconfig` global carga un `.gitconfig` del proyecto con `user.name` y el email *noreply* de la cuenta del proyecto (`<id>+<usuario>@users.noreply.github.com`; el repo es público y no debe exponer emails, [ADR-0043](../adr/0043-public-repo.md)).
     - **Hooks**: el `.gitconfig` del proyecto anula cualquier `core.hooksPath` global, y `pnpm install` lo fija también en el propio repo, para que solo corran los hooks del repo (lefthook, [ADR-0017](../adr/0017-verifiable-harness.md)).
     - **Credenciales**: clave SSH propia del proyecto con un alias de host en `~/.ssh/config` (`github-workampo`) y el remoto del repo usando ese alias; `gh` con la cuenta del proyecto en una configuración aparte (`GH_CONFIG_DIR`) y una función de shell que la usa solo dentro de la carpeta del proyecto. No se usa `gh auth switch` (la cuenta activa es global) ni `gh auth setup-git` (ayudante de credenciales global).
     - **Hooks globales de Claude Code**: los que un proyecto no puede desactivar se saltan este repo mediante una opción del `.gitconfig` del proyecto. ✅ Comprobado el 16 nov 2026 con el primer commit del agente (PR #1).
     - **Salvaguardas**: `pnpm work` comprueba que `gh` y el autor de git son la cuenta del proyecto (definida en `project.yaml`, [ADR-0045](../adr/0045-project-profile.md)) y se niega si no; CI rechaza PRs con commits cuyo email no sea el *noreply* del proyecto.
     - **Agentes**: el `CLAUDE.md`/`AGENTS.md` del repo deja claro que las reglas globales de la máquina no aplican aquí (las issues son de GitHub y la trazabilidad es la de [ADR-0042](../adr/0042-traceability.md)).
